# 02 · The artist with nothing

Which artists have no albums at all?

**Expected: 1 row — Chet Baker.**

If you got 0 rows, your join decided who exists: an inner join between artists
and albums can only ever return artists that have one. That is the whole
exercise. There are at least two ways out of it; write one, then say in a
comment what the other would have been and which you would defend in review.
