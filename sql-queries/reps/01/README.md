# 01 · Every album by one artist

List Miles Davis's albums, oldest first. Title and release year.

You do not know his `id`; find it from his name in the same query.

**Expected: 7 rows.** Six carry a release year, running from *Birth of the
Cool* (1957) to *Doo-Bop* (1992). The seventh is *Rubberband*, which has no
release year at all.

Where did *Rubberband* land in your ordering — first or last? Now: did **you**
decide that, or did Postgres? Find out which, and then make the query say it
out loud.
